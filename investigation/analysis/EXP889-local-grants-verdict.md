It does not prove every capacity or backing lifetime case on hardware. The combined goal (600 seconds without a kernel stop **and** nonzero scanout) remains unmet. The next causal boundary is standard Present/scanout ownership. Before a new architectural run, derive the Microsoft WDDM presentation contract, the Asahi/m1n1 producer-to-DCP contract, and the current KMD/UMD translation offline; isolate one missing invariant rather than returning to the closed grant-capacity hypothesis without contrary evidence.

## Evidence and recovery

The original Code0 evidence was copied and independently host size/SHA verified before any cleanup: 15 files, 586,252,508 bytes, manifest SHA-256 `c0512ba950b7870a2a10491e8caf1055fdecaa06438f00a51c7a1d3ad170cc84`. Original ETL receipt matches the boot; the ETL reached its 512 MiB cap and its logging session was absent when collection tried to stop it. The first collector correctly refused a reboot. A read-only check confirmed session absence and the same Code0 boot; an in-memory one-condition guard change allowed the original collector to finish without modifying the staged script. The ETL is original-boot evidence, but cannot be called an uninterrupted full-window trace. The included `093026-13265-01.dmp` predates EXP889 and belongs to EXP888.

Only after original host verification did recovery request an ordered restart. It stalled on the same original boot; the owning launcher SIGTERM captured its diagnostic snapshot and rebooted Air. Immutable GPU-hidden boot reached Code45 with the exact oem5 package, matching INF/SYS/UMD hashes, no arm and stopped service. Hidden supplement and watchdog collection completed, then 20 files/631,022,249 bytes were independently host size/SHA verified, manifest SHA-256 `f8b0807bcd18b1490b2bcc6faed8e1e16e54f5af3d955a51a0d4a0e69427b886`, **before** diagnostics and package cleanup. No new kernel/watchdog dump was captured.

The cleanup wrapper reverified every guest evidence file and exact Code45 identity before removing diagnostics and the exact package. Ordered cleanup restart returned to immutable ordinary GPU-visible recovery: boot `01:32:33.8116690Z`, durable verification `01:33:49.2053838Z`, Code28/one APPL0002, package0/arms0/SYS0/UMD0/service0/signer0/diagnostics0, eight CPUs, two OK disks, five OK USB devices, RDP service Running, `AutoAdminLogon=1` and password present.
