## Contract and single variable

EXP891 changed only the Windows package from EXP890's exact package889 to R169 package891. The m1n1 EXP890 measurement image (`d3e0f999...`) and MuR143 (`e54c0098...`) were byte-identical. The pinned WDK26100 `DXGKARG_PRESENT` and [Microsoft's Present-argument documentation](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/d3dkmddi/ns-d3dkmddi-_dxgkarg_present) define `pAllocationList[1]` as the source and `[2]` as the destination; either handle may be null if that endpoint is absent. The `pAllocationInfo` union alias is reserved for system use and must not be interpreted as an alternative driver-facing array. For GPUVA `NoPatchingRequired`, the patch list may be absent.
