## Ownership and smallest discriminator

Windows/dxgkrnl owns DWM's DDI ordering and scheduler/fence calls. KMD owns callback acceptance, allocation validation, source-address queue and truthful caps. m1n1 owns DCP swap/latch and late surface snapshot. Mu owns the reserved physical range/ACPI exposure, not pixel production. Recovery remains immutable GPU-hidden Code45 exact-package cleanup only after independently host-verified original and hidden evidence, then ordinary GPU-visible Code28/package0/autologon1; never remove a live Code0 package.

`WINDOWS CONTRACT:` A full graphics DWM primary may reach BLT/flip Present, source-address MMIO flip, and virtual submit, according to the advertised caps. MPO/display-only entry points are unregistered. `AGX/ASAHI CONTRACT:` Valid local primary buffer and m1n1 DCP queue/latch must carry the selected pixels; no new UAT/DCP behavior is assumed. `TRANSLATION:` Add bounded, passive per-registered-DDI counters and last input/status (source address, allocation, flags, fence and submit shape) readable after the boot; retain late matched DCP snapshots at +120/+300/+600. `WHAT IS STILL UNKNOWN:` Which DDI actually carries DWM's primary, whether it succeeds, and whether its address/allocation matches the latched DCP surface. The one receipt-only hardware run resolves this ordering question; no driver behavior or firmware change is allowed in it.

`WHY THIS HYPOTHESIS:` (1) EXP894/895 DWM stays alive but the existing BLT Present receipt is absent; another advertised display/flip entry may carry its primary. (2) `SetVidPnSourceAddress` is registered and is the only current callback that queues a DCP present, while its current receipt records only the first call. (3) late matched DCP pixels remain zero, so counting real callbacks and their last allocation/address directly distinguishes no-caller from reject/mismatch. The hardware variable is **only passive DDI measurement**; exact behavior/caps/firmware/Mu remain unchanged.

No EXP896 build or hardware launch is authorized until the counter implementation is reviewed, tested for noninterference/IRQL safety, built 0 warnings/errors, hashed/preregistered with recovery artifact, and BEFORE ledger is complete. DWM crash/writer remains separate.

## Proposed bounded measurement design for supervisor review

Add one fixed-size, nonpaged diagnostic state in `ADMISSION_CONTEXT` with independent atomic call counts and last-input/last-return fields for the **registered** entry points: Present BLT, Present flip, Present other; source-address; CommitVidPn; SubmitCommandVirtual Present and non-Present. Do not fabricate counters for MPO or PresentDisplayOnly (unregistered); report them as unavailable in the schema. Source-address capture records `VidPnSourceId`, `hAllocation`, `PrimarySegment`, `PrimaryAddress`, flags, and return status. Present captures flags, source/destination allocation counts, return status. Submit captures flags, context, GPUVA, fence, and return status. Commit captures source, powered-off flag, and status. No pointer dereference solely for diagnostics, no allocation, lock, registry I/O, wait, or change in return value from callback paths. Capture at entry and every return through a single terminal assignment where practical; for early returns, record a reason/status before return. An existing passive query/escape or bounded registry flush at PASSIVE_LEVEL should expose a snapshot at +120/+300/+600, including counts even if no callback was invoked. Use interlocked operations or an explicit sequence protocol so a torn last-value is identified, not misread as a real allocation. Keep the current first-call receipt unchanged for comparison.

Review gate: demonstrate a deterministic offline replay of each counter increment and last-input/status including rejection and concurrent snapshot; the measurement's regression test catches missing or reordered capture, not an invented DWM behavior. Pin expected zero counts for unregistered DDIs, but do not advertise new caps. Then package an exact one-variable EXP896, retain immutable hidden/ordinary recovery, enforce original and final host evidence gates, and do not infer a Present path from a missing BLT receipt alone.
