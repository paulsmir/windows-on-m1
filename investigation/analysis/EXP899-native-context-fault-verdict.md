# EXP899: DWM context fault precedes native Present

Receipt-only package `30.0.899.0` preserves the EXP898 DXGI, KMD, firmware, and Mu behavior. In original boot `2026-09-30T14:58:00.3530810Z`, the first and sampled later DWM PID 1236 `_Present` calls entered `AgxD3d10WindowsPresentationSubmit` with `any_faults=1`, backend failed=0, batch present=0, draws=0, LastScreenError=0, DrawTerminal=0. `AgxWin32AsahiContextFlushForPresent` returned `E_FAIL` without changing this state. `AgxD3d10WindowsFlushStatus` and `pfnPresentCb` were not called. Thus the original DWM blocker is an earlier native context fault, not a new fault in Present, a FlushStatus error, missing DXGI entry, or KMD Present. The first setter site is not observed.

Code0/CPU8/SSH/RDP/USB/storage stayed alive beyond 775.095 seconds without an observed kernel stop. DWM1236 was replaced by PID1412; Application1000 reported d2d1/d3d11 C0000005 but no new WER/kernel dump, so its writer remains separate. The current DCP swap11 sequence3 surface IOVA `0x102a0000` matched late +120/+300/+600; each 4,096,000-pixel sample was zero (`cache_clean=0`). Goal unmet.

Original capped ETL SHA `9e4d7a45e34a24cf597f6654ecf437548c0f8b2216141e3d3391924f9efaa3f1` and ten other original files were independently host size/SHA verified before recovery. The packaged original collector stopped at the already-absent capped ETL session; a byte-identical guest hardlink and receipt passed its original contract before reset. Ordered restart then stalled after System1074. After the original host gate, only owning `run_uefi` was terminated. Immutable hidden boot reached Code45/exact oem5/serviceStopped/armnull, but the guest original evidence directory was unexpectedly absent and C: nearly full. Rather than assuming persistence or running the large supplement, a 3,119-byte hidden exact-state/events inventory was written under the existing package directory and independently host size/SHA verified. Final manifest `.local/experiments/EXP899-probe-symbols/final-host-manifest.json` SHA `985c5077aa488c0b8cc400f778e9ea20d87a6c6b63b726c8243c166e306f5264` ties original 11/11 and hidden 1/1 gates before exact Code45 cleanup. Ordinary recovery at `2026-09-30T15:37:30Z` proved one GPU-visible Code28 APPL0002, package/arm/service/module/signer/diagnostics absent, CPU8, both disks OK, USB5, RDP running, autologon1. No package was removed from live Code0. Under Code28, two other independently hostverified guest evidence duplicates were byte-gated and removed to restore C: headroom; host artifacts were retained.

The generated native `agx_flush_batch` had a deterministic no-work lifecycle defect: it marked `any_faults` then aborted/reset an empty active batch, producing precisely the observed pre-Present shape. The pinned upstream Asahi/Mesa function resets a no-work batch without fault. R179 commit `45ec717a0893b82d4e6cb00177adddc23fbe7a77` fixes only that no-work branch, preserving fail-closed active work and failed abort. An extracted-body ASan/UBSan test was RED on the old implementation and GREEN on R179. This is an independently proven software defect, **not proof that DWM took the branch**. EXP900 is a single-variable behavior-only hardware discriminator: if DWM's first native Present preFault clears and reaches its callback, the hypothesis gains support; if it remains faulted, locate the actual first setter rather than stacking behavior changes. DWM crash remains separate.
