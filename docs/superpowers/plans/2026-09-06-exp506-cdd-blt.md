## Implemented offline contract and verification supplement

Present now normalizes the actual505 buffered Flags1 operation through fixed
allocation slots1/2, captures pointer-free descriptions/geometry and emits both
patch references. Prepatch can proceed straight to Submit; optional Patch
rebinds both endpoints after validating the complete pair. Submit snapshots the
selected command and binds its actual Windows fence. No copy is executed during
preparation or relocation, and open-object/borrowed-MDL pointers are not retained.

CPU paging/copy payloads and AGX render dispatch share the existing one-engine
fence ordering through a bounded64-entry FIFO. CPU payloads have a matching FIFO,
and activation occurs only at the shared head after prior work retires. The CPU
slot is released before OS NotifyDpc; active worker/DPC counters keep teardown
from freeing the owner while callbacks return. Preemption/reset discard only
queued payloads and preserve an active operation's boundary. AGX completion
reservations remain held through actual interrupt/DPC reporting; preemption and
an unrelated VSync DPC cannot release an unreported completion. Canceled or
deferred render wakes do not fault an unrelated CPU job. Backend worker idle
publication is serialized with successor enqueue, including nested returns;
a bounded second dispatch attempt closes the preceding-worker lost-wakeup race.

Scope limits: one-to-one BGRA8888 copy, resident source local2 or live aperture1,
destination local2. Local backing is rounded64KiB while logical pixel bounds are
retained. Shifted same-allocation overlap that would require multiple packets is
rejected before any output; general overlapping multipass is not claimed. FIFO
capacity is64 pending operations; arbitrary-capacity pressure is not established
by this candidate. No new graphics capabilities, nodes, hardware protocols or
OpenGL support are advertised. CPU copy/fence evidence stays separate from AGX.

WHY THIS HYPOTHESIS: EXP505 captured a valid CDD Flags1 BLT with real DMA4096,
private8192, fixed allocation-list convention and one full native rectangle.
Current Present accepts only null-DMA Flags4 flips. This is a missing copy
operation, not a flags bug. All earlier hardware layers remain accepted.

WINDOWS CONTRACT: FULL GRAPHICS physical WDDM3.0 Present compiles pointer-free
commands and source-read/destination-write patch references for fixed list slots
1/2; physical CDD counts0 do not replace those slots. Nonzero allocation SegmentId
must be prepatched, and later Patch remains legal; the actual submitted fence
is bound at Submit so the no-Patch path works. Source/destination rectangles
define a 1:1 mapping; clipped destination subrectangles select copied pixels.
No bytes are copied or completed during Present/Patch preparation. Submit runs
at DISPATCH; actual CPU transfer is deferred using existing paging work ownership
and synchronized interrupt/DPC completion. Microsoft documents software-engine
completion in DxgkCbNotifyInterrupt. A CPU presentation transfer is not AGX
rendering and will never count as TA3D/OpenGL/CS1.6 hardware acceptance.

AGX/ASAHI CONTRACT: existing Asahi/IOMFB/DCP owner scans the resident primary;
the Windows CDD shadow is CPU-produced surface data. Current AGX backend has
actual color-fill rendering but no source-reading BLT shader. Preserve that
hardware rendering backend while implementing the required presentation data
movement separately. No firmware/MMIO/UAT/interrupt ownership changes. Native477,
Mu406, physical initial swap/latch and internal latch IRQ mapping stay accepted.

TRANSLATION: a bounded BLT record snapshots validated allocation descriptions,
rectangles, context identity and encoded segment/address endpoints, never open
object pointers. Present normalizes/encodes and emits both references; Patch
updates residency only. Submit validates the selected private command range,
binds the exact fence and queues the copy on existing CPU-transfer work ownership.
Memory runtime owns source-local or live-aperture reads and local-primary writes.
Read aperture pages under its PagingLock with the current page resolver and
MmCopyMemory physical reads of Windows PFNs; do not treat dummy entries as live
or PFNs as host physical addresses. Nonpaged scratch snapshots source pixels
before any destination write, preserving overlap. Existing noncached local view
and barrier precede completion. Primary destination is local segment2 by the
accepted allocation contract; no undocumented aperture write mapping is added.
Keep lifecycle, cancellation and existing scheduler/fence ownership coherent.

ATOMIC CONTRACT: encoding + both patch references/prepatch + residency rebinding
+ submitted data movement + exact completion form one Present BLT operation.
Accepting the call without copy, moving data during preparation, sealing only
in optional Patch, or completing before visibility would violate the same copy
contract. No independent capabilities, topology or preemption settings change.
