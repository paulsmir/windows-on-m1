Goal: remove the EXP1909 format-copy refusal and fix the next independently
proven, common DDI restriction; account for every generator refusal in the handoff.
Spec: `/Volumes/pwdev/public_windows/.local/handoff/codex/t2-d3d11-notimpl-audit/TASK.md`.
Execution is authorized end to end by the user, in the existing isolated worktree.

Sources inspected: generator ResourceCopyRegion/ResourceCopy and resource guards;
WDK 26100 d3d10umddi.h; Microsoft CopySubresourceRegion and Format Conversion using
Direct3D 10.1; combined D3D11 functional spec 5.6; Mesa agx_blit.c:557-664,
agx_pipe.c:1798-1804 and u_surface.c:204-350. Full evidence goes in REPORT.md.

Contract: Windows format groups and source texel/destination pixel coordinates
are translated by the frontend. Asahi owns transfer synchronization and tiled
storage mapping. Gallium's utility scales full-block cross-format copies, but
its compressed-source shrink uses integer division and cannot represent a
sub-block mip copied to an uncompressed texel. Explicit mapped block copies can
cover those tails without modifying Mesa. Firmware, interrupts, DMA ownership,
power and recovery contracts are unaffected; no live-state measurement is needed.
No upstream implementation code is copied.

- [x] Run targeted tests and baseline; commit P0 independently.
- [x] Apply equivalent whole-resource copy support in a separate tested commit.
- [x] Finish exhaustive audit, distinguish overridden stubs, rank remaining gaps.

Review focus: integer-vs-float compatibility, reverse-copy tail mips, cube/array
slices, scaled destination bounds, preserving block bits without decoding.
